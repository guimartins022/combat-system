## Sistema de Combate Simples em Java

Projeto simples feito em Java para praticar conceitos de Programação Orientada a Objetos.

O código simula um pequeno sistema de combate entre um herói e um monstro em um grid. Cada personagem possui vida e pode se mover ou atacar se estiverem próximos.

## Conceitos utilizados

- Herança
- Enum
- Sobrescrita de métodos
- Lógica de posição em grid

## Estrutura do projeto

- **Jogador** → classe base com vida, posição, ataque e movimentação  
- **Heroi** → herda de Jogador e possui ataque mais forte  
- **Monstro** → herda de Jogador e representa o inimigo  
- **Direcao** → enum usada para movimentação no mapa  
- **Jogo** → classe principal para executar a simulação

## Objetivo

Praticar conceitos básicos de POO em Java como herança, organização de classes e interação entre objetos.
